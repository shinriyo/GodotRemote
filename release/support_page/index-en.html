REMOTE PLAYTESTING

Playtest your Mac game on your iPhone.

View a running Godot game on your iPhone and send taps and drags back to your Mac.

Tested with Godot 4.7.2. Other 4.x versions are unverified. This is a development version; the App Store edition is not yet available.

Download the app

App Store: preparing for release

Google Play: not released; store URL unavailable

You need both the iPhone client and the game-side addon

Installing the iPhone app alone is not enough. Add and enable the free server addon in each game project you want to control, then run the game. You need a Mac, Godot 4.7.2, a compatible iPhone client, and a LAN that allows the devices to communicate. The game runs on the Mac; this does not replace testing a native iOS build.

First-time setup

01

Copy the free addon

Get the development source. Copy the entire godot4/addons/godot_remote folder into your game's addons/ folder.

The repository's root-level addons/ contains the old Godot 3 version. Do not copy that version.

02

Enable the plugin in Godot

Open your game project. In Project Settings → Plugins, enable Godot Remote 4. Run the game, or stop and restart it if it is already running.

03

Open the iPhone client on the same LAN

Connect both devices to the same LAN. Open the iPhone app and allow Local Network access.

04

Select your game and connect

Select the running game from the list, then press Connect. The address is filled in automatically. If you configured a server password, enter the same password.

Your game/
├── project.godot
└── addons/
    └── godot_remote/
        ├── plugin.cfg
        ├── autoload.gd
        ├── server.gd
        └── …

Keep your game's existing project.godot. No extra nodes are needed. Install the addon separately in each project. The App Store client is not released yet; see the README for instructions to build the iPhone client yourself.

After connecting

Tap or drag on the game image. Settings hide after connection: use Settings to open them, Hide to return, and Disconnect to end the session. Turn your iPhone sideways for a larger view of landscape games. About / Licenses shows copyright notices. Moving the app to the background disconnects it; reconnect when you return.

Connection troubleshooting

How do I set or remove a connection password?

Enable Godot Remote 4 in your Mac game project. Open Project → Project Settings → General, enable Advanced Settings, and search for godot_remote/server. Set Password (godot_remote/server/password), then stop and restart the game. Enter the same value in the iPhone client’s Password field before connecting. The default is empty and needs no password. To remove it, clear the server setting, restart the game, and clear the client field too. Re-enter the password after relaunching the app. Traffic and passwords are unencrypted; use a trusted LAN.

Is the addon available in the Godot Asset Store?

Currently, copy the addon from the GitHub source linked above. The free game-side addon can be submitted to the Godot Asset Store; this guide does not indicate a published or approved listing. Submission preparation includes a Godot 4-only ZIP, README, LICENSE and copyright notices, an English description, supported versions, and client installation and connection instructions. See the official submission guide. Godot’s addon store is separate from Apple’s App Store for the iPhone app.

The plugin is missing from Godot

Check that your game contains addons/godot_remote/plugin.cfg. Avoid a nested duplicate folder and the old Godot 3 addon.

No games appear on iPhone

Enable the plugin and restart the game. Check Local Network permission and LAN connectivity. Guest Wi-Fi may block device-to-device traffic. Automatic discovery currently supports Mac servers and iPhone clients.

The game appears but will not connect

Check the password, Mac-side errors and firewall access for Godot. If the permission prompt caused a timeout, press Connect again.

Can I enter the address manually?

Enter the Mac's LAN IP and port (default 22766). Do not enter 127.0.0.1 on iPhone: that refers to the iPhone itself.

The Mac reports ‘cannot listen’

Another game may be using the same port. Set different values for godot_remote/server/port when running multiple games.

How do I update or remove the addon?

Stop the game, replace the addon folder with the new version, and run again. Updates are manual. To remove it, disable the plugin before deleting its folder.

Source code and the Mac addon are available free under MIT. We are preparing a one-time-purchase App Store edition that needs no manual build or signing. Revenue will support this app's development and maintenance, not donations to Godot Engine or the original author.

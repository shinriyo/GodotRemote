REMOTE PLAYTESTING

Mac의 게임을 iPhone에서 직접 조작하며 테스트하세요.

실행 중인 Godot 게임을 iPhone에 표시하고 탭과 드래그 입력을 Mac으로 보냅니다.

Godot 4.7.2에서 동작을 확인했습니다. 다른 4.x 버전은 미검증입니다. iOS 4.0.0 버전이 App Store에 출시되었습니다.

앱 다운로드

Google Play: 미출시, 스토어 URL 미정

iPhone 앱과 게임 측 애드온이 모두 필요합니다

iPhone 앱만 설치해서는 연결할 수 없습니다. 조작하려는 게임 프로젝트마다 무료 서버 애드온을 추가하고 활성화한 다음 게임을 실행하세요. Mac, Godot 4.7.2, 호환되는 iPhone 클라이언트, 두 기기 간 통신이 가능한 동일 LAN이 필요합니다. 게임은 Mac에서 실행되며, 이 도구는 네이티브 iOS 빌드 테스트를 대신하지 않습니다.

처음 설정하기

01

무료 애드온 다운로드

Godot Asset Store에서 무료 서버 애드온 ZIP을 다운로드하고 addons/godot_remote를 게임 프로젝트에 압축 해제합니다. 프로젝트 설정 → 플러그인에서 SHINRIYO Remote Server for Godot 4를 활성화한 후 게임을 다시 실행합니다.

2026년 10월 28일 공개: 4.0.0-dev는 Unstable 버전이며 최소 및 최대 지원 버전은 Godot 4.7.2입니다. README와 플러그인 표시 이름을 통일했습니다. 게임 측 애드온이며 iPhone 클라이언트의 출시 상태는 별도입니다.

GitHub

개발 버전 소스를 받아 godot4/addons/godot_remote 폴더 전체를 게임의 addons/ 폴더에 복사하세요.

저장소 최상위의 addons/는 이전 Godot 3 버전입니다. 해당 버전을 복사하지 마세요.

02

Godot에서 플러그인 활성화

게임 프로젝트를 열고 프로젝트 설정 → 플러그인에서 SHINRIYO Remote Server for Godot 4를 활성화하세요. 게임을 실행하거나, 이미 실행 중이라면 중지 후 다시 실행하세요.

03

같은 LAN에서 iPhone 앱 열기

Mac과 iPhone을 같은 LAN에 연결하세요. iPhone 앱을 열고 로컬 네트워크 접근을 허용하세요.

04

게임 선택 후 연결

목록에서 실행 중인 게임을 선택하고 Connect를 누르세요. 주소는 자동으로 입력됩니다. 서버에 비밀번호를 설정했다면 동일한 비밀번호를 입력하세요.

Your game/
├── project.godot
└── addons/
    └── godot_remote/
        ├── plugin.cfg
        ├── autoload.gd
        ├── server.gd
        └── …

게임의 기존 project.godot를 유지하세요. 별도 노드를 추가할 필요가 없습니다. 애드온은 프로젝트마다 설치해야 합니다. App Store에서 클라이언트를 받을 수 있습니다. 직접 iPhone 클라이언트를 빌드하려면 README를 참고하세요.

연결 후 조작

게임 화면을 탭하거나 드래그하세요. 연결되면 설정 영역이 숨겨집니다. Settings로 설정을 열고, Hide로 돌아가며, Disconnect로 연결을 종료합니다. 가로형 게임은 iPhone을 가로로 돌리면 더 크게 볼 수 있습니다. About / Licenses에서 저작권과 라이선스를 확인할 수 있습니다. 앱이 백그라운드로 이동하면 연결이 끊어지므로 돌아온 뒤 다시 연결하세요.

연결 문제 해결

연결 비밀번호는 어떻게 설정하거나 해제하나요?

Mac의 게임 프로젝트에서 SHINRIYO Remote Server for Godot 4를 활성화합니다. 프로젝트 → 프로젝트 설정 → 일반에서 고급 설정을 켜고 godot_remote/server를 검색합니다. Password(godot_remote/server/password)를 설정한 다음 게임을 중지하고 다시 실행합니다. iPhone 클라이언트의 Password에도 같은 값을 입력하고 연결합니다. 기본값은 빈칸이며 비밀번호가 필요 없습니다. 해제하려면 서버 설정을 비우고 게임을 다시 실행한 후 클라이언트 입력란도 비웁니다. 앱을 다시 시작하면 비밀번호를 다시 입력해야 합니다. 통신과 비밀번호는 암호화되지 않으므로 신뢰할 수 있는 LAN에서 사용하세요.

Godot 공식 스토어에서 받을 수 있나요?

Godot Asset Store — SHINRIYO Remote Server for Godot 4. 2026년 10월 28일 공개: 4.0.0-dev는 Unstable 버전이며 최소 및 최대 지원 버전은 Godot 4.7.2입니다. README와 플러그인 표시 이름을 통일했습니다. 게임 측 애드온이며 iPhone 클라이언트의 출시 상태는 별도입니다.

Godot 플러그인 목록에 표시되지 않아요

게임에 addons/godot_remote/plugin.cfg가 있는지 확인하세요. 폴더가 이중으로 중첩되거나 이전 Godot 3 애드온을 설치하지 않았는지 확인하세요.

iPhone에 게임이 표시되지 않아요

플러그인을 활성화하고 게임을 다시 실행하세요. 로컬 네트워크 권한과 LAN 연결을 확인하세요. 게스트 Wi-Fi는 기기 간 통신을 차단할 수 있습니다. 자동 검색은 현재 Mac 서버와 iPhone 클라이언트에 대응합니다.

게임은 보이는데 연결되지 않아요

비밀번호, Mac 측 오류, Godot의 방화벽 허용 여부를 확인하세요. 권한 안내 중 시간이 초과되었다면 Connect를 다시 누르세요.

주소를 직접 입력할 수 있나요?

Mac의 LAN IP와 포트(기본값 22766)를 입력하세요. iPhone에서 127.0.0.1은 iPhone 자체를 가리키므로 사용하지 마세요.

Mac에 cannot listen 오류가 나요

다른 게임이 같은 포트를 사용하고 있을 수 있습니다. 여러 게임을 동시에 실행할 때는 godot_remote/server/port를 서로 다르게 설정하세요.

업데이트하거나 삭제하려면?

게임을 중지하고 애드온 폴더를 새 버전으로 교체한 후 다시 실행하세요. 자동 업데이트는 없습니다. 삭제할 때는 먼저 플러그인을 비활성화한 다음 폴더를 삭제하세요.

무료 소스와 개발을 지원하는 유료 버전

소스 코드와 Mac 애드온은 MIT 라이선스로 무료 공개합니다. 직접 빌드하거나 서명할 필요 없이 한 번 구매하여 사용할 수 있는 App Store 버전을 제공합니다. 수익은 이 앱의 개발과 유지보수에 사용되며, Godot Engine이나 원작자에 대한 기부가 아닙니다.

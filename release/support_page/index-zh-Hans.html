REMOTE PLAYTESTING

在 iPhone 上操作并测试 Mac 上的游戏。

在 iPhone 上查看正在运行的 Godot 游戏，并将点击和拖动操作发送回 Mac。

已在 Godot 4.7.2 上验证。其他 4.x 版本尚未验证。iOS 4.0.0 版本已在 App Store 上架。

下载应用

Google Play：尚未发布，商店链接未确定

需要 iPhone 客户端和游戏端插件

仅安装 iPhone 应用无法连接。请在每个需要操作的游戏项目中添加并启用免费服务器插件，然后运行游戏。需要 Mac、Godot 4.7.2、兼容的 iPhone 客户端，以及允许两台设备通信的同一局域网。游戏在 Mac 上运行，不能代替对原生 iOS 构建的测试。

首次设置

01

下载免费插件

从 Godot Asset Store 下载免费的服务器插件 ZIP，将 addons/godot_remote 解压到游戏项目。在项目设置 → 插件中启用 SHINRIYO Remote Server for Godot 4，然后重新运行游戏。

2026年10月28日已公开：4.0.0-dev 标记为 Unstable，最低和最高支持版本均为 Godot 4.7.2。README 与插件显示名称已统一。这是游戏端插件，iPhone 客户端的发布状态另行说明。

GitHub

获取开发版源码，将整个 godot4/addons/godot_remote 文件夹复制到游戏的 addons/ 文件夹中。

仓库根目录下的 addons/ 是旧 Godot 3 版本，请勿复制该版本。

02

在 Godot 中启用插件

打开您的游戏项目，在项目设置 → 插件中启用 SHINRIYO Remote Server for Godot 4，然后运行游戏。如果游戏已在运行，请停止后重新运行。

03

在同一局域网中打开 iPhone 应用

将 Mac 和 iPhone 连接到同一局域网，打开 iPhone 应用并允许访问本地网络。

04

选择游戏并连接

在列表中选择正在运行的游戏，然后点击 Connect。地址会自动填入。如果服务器设置了密码，请输入相同的密码。

保留游戏原有的 project.godot，无需额外添加节点。每个项目都需要单独安装插件。客户端可从 App Store 获取；如需自行构建 iPhone 客户端，请参阅 README。

连接后的操作

点击或拖动游戏画面即可操作。连接后设置区域会隐藏：点击 Settings 打开设置，点击 Hide 返回，点击 Disconnect 断开连接。横屏游戏可将 iPhone 横放以获得更大画面。About / Licenses 可查看版权和许可证。应用进入后台会断开连接，返回后请重新连接。

连接故障排查

如何设置或取消连接密码？

在Mac上的游戏项目中启用SHINRIYO Remote Server for Godot 4。打开项目 → 项目设置 → 常规，启用高级设置，搜索godot_remote/server，设置Password（godot_remote/server/password）。停止并重新运行游戏，然后在iPhone客户端的Password栏中输入相同密码。默认留空，无需密码。取消密码时，清空服务器设置并重新运行游戏，同时清空客户端密码栏。重新启动应用后需要重新输入密码。通信和密码均未加密，请在可信的局域网内使用。

可以从Godot官方商店获取插件吗？

Godot Asset Store — SHINRIYO Remote Server for Godot 4. 2026年10月28日已公开：4.0.0-dev 标记为 Unstable，最低和最高支持版本均为 Godot 4.7.2。README 与插件显示名称已统一。这是游戏端插件，iPhone 客户端的发布状态另行说明。

Godot 插件列表中没有显示

确认游戏目录中存在 addons/godot_remote/plugin.cfg，避免重复嵌套文件夹，也不要使用旧 Godot 3 插件。

iPhone 上没有显示游戏

启用插件并重新运行游戏。检查本地网络权限和局域网连接。访客 Wi-Fi 可能禁止设备之间通信。自动发现目前支持 Mac 服务器和 iPhone 客户端。

能看到游戏，但无法连接

检查密码是否一致、Mac 端是否有错误，以及防火墙是否允许 Godot 通信。如果授权提示导致超时，请再次点击 Connect。

可以手动输入地址吗？

输入 Mac 的局域网 IP 和端口（默认 22766）。不要在 iPhone 上输入 127.0.0.1，它指向 iPhone 自身。

Mac 显示 cannot listen

可能有其他游戏正在使用同一端口。运行多个游戏时，请为 godot_remote/server/port 设置不同的值。

如何更新或删除插件？

停止游戏，将插件文件夹替换为新版本，然后重新运行。插件不会自动更新。删除前请先禁用插件，再删除文件夹。

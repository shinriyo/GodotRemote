隐私政策

更新日期：2026年10月20日 · 运营者：SHINRIYO

应用通信

本应用从您连接的 Mac 接收游戏画面，并将触摸、鼠标、键盘输入以及设备可获取的加速度、重力、陀螺仪和磁力计数据发送到该主机。兼容的游戏还可以交换自定义数据。这些数据用于远程测试。

当前实现不包含广告 SDK、分析 SDK，也没有将这些画面、输入或传感器数据发送到开发者服务器的功能。所连接游戏自身的数据处理方式取决于该游戏。

发现服务与权限

应用通过 Bonjour 查找局域网中的兼容游戏。本地网络权限用于发现与连接，设备运动信息作为传感器输入发送给已连接的游戏。

设备本地保存的数据

应用在设备本地保存连接地址和端口，方便下次连接。连接密码不会写入设置文件。应用没有录制或保存接收视频的功能。删除应用及其数据即可清除连接设置。

网络安全

当前通信未加密，包括连接密码。请仅在可信的局域网中使用，不要将端口暴露到互联网。

支持网站与外部服务

本网站没有自行设置的访问分析、广告或联系表单。托管服务商 Netlify 可能为了提供和运营网站而处理 IP 地址等请求信息。请参阅 Netlify 隐私政策。

GitHub 上的咨询内容是公开的。使用 GitHub 或 Apple 服务时，适用各自的隐私政策。

联系与更新

如对本政策有疑问，请通过 GitHub Issues 联系。实现或数据处理方式发生变化时，我们会更新本页及更新日期。

앱 통신

이 앱은 사용자가 연결한 Mac에서 게임 영상을 수신하고, 터치·마우스·키보드 입력과 기기에서 제공되는 가속도·중력·자이로스코프·자기장 센서 값을 해당 호스트로 보냅니다. 호환되는 게임에서는 사용자 정의 데이터도 주고받을 수 있습니다. 이 데이터는 원격 테스트에 사용됩니다.

현재 구현에는 광고 SDK, 분석 SDK 또는 이러한 영상·입력·센서 데이터를 개발자 서버로 전송하는 기능이 없습니다. 연결된 게임 자체의 데이터 처리는 해당 게임의 정책과 구현을 확인하세요.

검색 및 권한

Bonjour를 이용해 로컬 네트워크의 호환 게임을 찾습니다. 로컬 네트워크 권한은 검색과 연결에 사용됩니다. 기기 모션 정보는 연결된 게임에 센서 입력으로 전달됩니다.

기기에 저장되는 정보

다음 연결을 위해 접속 주소와 포트를 기기에 저장합니다. 접속 비밀번호는 설정 파일에 저장하지 않습니다. 수신 영상을 녹화하거나 저장하는 기능은 없습니다. 앱과 앱 데이터를 삭제하면 연결 설정을 삭제할 수 있습니다.

네트워크 보안

현재 통신은 암호화되지 않으며 접속 비밀번호도 평문으로 전송됩니다. 신뢰할 수 있는 LAN에서 사용하고 포트를 인터넷에 공개하지 마세요.

지원 웹사이트 및 외부 서비스

이 사이트에는 자체 방문 분석, 광고 또는 문의 양식이 없습니다. 호스팅 제공업체 Netlify는 사이트 제공과 운영을 위해 IP 주소 등의 요청 정보를 처리할 수 있습니다. Netlify 개인정보 처리방침을 확인하세요.

GitHub 문의 내용은 공개됩니다. GitHub 및 Apple 서비스 이용 시에는 각 서비스의 개인정보 처리방침이 적용됩니다.

문의 및 변경

본 방침에 관한 문의는 GitHub Issues로 보내주세요. 구현이나 데이터 처리 방식이 변경되면 이 페이지와 업데이트 날짜를 수정합니다.

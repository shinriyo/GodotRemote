Privacy Policy

Updated: October 20, 2026 · Operator: SHINRIYO

App communication

The app receives game images from the Mac you connect to and sends touch, mouse and keyboard input, plus available accelerometer, gravity, gyroscope and magnetometer values to that host. Compatible games can also exchange custom data. This data is used for remote playtesting.

The current implementation has no advertising SDK, analytics SDK or feature that sends these images, inputs or sensor readings to the developer's servers. The connected game's own data handling depends on that game.

Discovery and permissions

Bonjour discovers compatible games on the local network. Local Network permission is used for discovery and connection. Device motion information is used as sensor input for the connected game.

Data stored on your device

The host address and port are saved locally for your next connection. The connection password is not saved to the settings file. The app has no feature to record or save received video. Connection settings can be removed by deleting the app and its data.

Network security

Current traffic is not encrypted, including connection passwords. Use a trusted LAN and do not expose the port to the internet.

Support website and external services

This site has no custom analytics, advertisements or contact form. Hosting provider Netlify may process request information such as IP addresses to deliver and operate the site. See Netlify's privacy policy.

GitHub support posts are public. GitHub and Apple apply their own privacy policies when you use their services.

Contact and updates

For questions about this policy, use GitHub Issues. We will update this page and its date when implementation or data practices change.

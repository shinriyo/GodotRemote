# Godot 4 source release and iOS 4.0.0 availability

## Available now

SHINRIYO Remote for Godot 4 version 4.0.0 is publicly available on the [Japanese App Store](https://apps.apple.com/jp/app/shinriyo-remote-for-godot-4/id6824852108). Apple’s public listing reports release time 2026-11-13 07:21:32 UTC and a one-time price of JPY 500. There are no subscriptions or in-app purchases. Regional availability and prices may differ.

## Source release

PR #1 adds a separate Godot 4 implementation under `godot4/`, retaining the original Godot 3 sources. It includes a free MIT-licensed server addon, JPEG game-view streaming, touch/mouse/keyboard forwarding, sensor/custom-message support, and Mac-to-iPhone Bonjour discovery. The iPhone UI expands the game view after connection and keeps connection settings separate from forwarded input. Original licenses remain available in About / Licenses.

This source release also includes a regression-tested Bonjour lifecycle fix: callbacks received after stopping discovery must not restart service resolution or restore obsolete endpoints.

## Setup and limitations

Install `godot4/addons/godot_remote` into each game project and enable **SHINRIYO Remote Server for Godot 4**. Run the game on the Mac and connect the iPhone on the same trusted LAN. The iOS app alone is insufficient. See the [setup guide](https://shinriyo-remote.netlify.app/index-en.html) and [Godot 4 README](../README.md).

Godot 4.7.2 is the verified version. Other Godot 4.x versions, Android store distribution, and native exported-game performance are not established by this release. LAN transport is unencrypted. The legacy Godot 3 protocol is incompatible; H.264 and several legacy features remain unported.

## Validation and provenance

The PR source was rechecked on macOS with Godot 4.7.2: script compilation, mobile UI, TCP integration, and discovery tests passed. The Swift lifecycle regression failed before the fix and passed after it. No GitHub Actions checks are configured for this PR. A cloud attempt using Godot 4.6.3 crashed before test execution and is not a passing compatibility test.

The source tag `godot4-source-2026-11-13` identifies the merged source snapshot, **not** a verified reproducible source tag for App Store build 4. The exact build 4 source-to-archive mapping remains unverified; the retained local distribution manifest describes build 3. No IPA is attached and no claim of binary reproducibility is made.
